# Travel México · Mi México. A Mi Manera. (Edición en Español)

Aplicación web independiente para **Mi México. A Mi Manera.**, que permite a los viajeros diseñar viajes a medida por Baja California y el Caribe Mexicano.

## Características
- **Creador de Experiencias**: 17 filtros temáticos accesibles en un diseño optimizado de 3 columnas.
- **22 Destinos con Fuentes**: Fotografías de alta resolución e información editorial para 22 destinos de Baja California y el Caribe Mexicano.
- **Simulación Dinámica de Itinerarios**: Planificación de itinerarios de varios días con ritmo personalizado y actividades reales.
- **Exportación a PDF en el Cliente**: Generación de guías profesionales en formato PDF con un solo clic.

## Desarrollo

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
```
